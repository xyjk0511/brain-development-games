打开方式：
1. 解压 zip。
2. 双击 index.html，或把 index.html 拖到浏览器中。
3. 不需要联网，不需要安装依赖。

试玩路径：
首页卡片 → 详情/说明 → 封面页 → 6 屏场景内教学 → 准备开始 → 低压练习 → 正式训练 → 结算页。

自适应难度：
结算页会显示“本轮表现”和“下轮推荐难度”。推荐难度保存在浏览器 localStorage 中，下一轮会按正确率、平均用时、提示次数自动调整。1-3 级为轻松关卡，7 级及以上标为“进阶挑战”。
