# category-fluency Design Note

## Identity

- `gameId`: `category-fluency`
- Chinese title: 词语分类园
- Domain: 语言
- Task family: semantic categorization / lexical-semantic access

## Evidence basis

- Primary paradigm: semantic categorization and verbal category knowledge.
- Paper/article references: semantic categorization and verbal fluency task literature.
- Open-source/task-library references: jsPsych text/button response plugins and language-task examples.

## MVP mechanics

- Show a category cue.
- Present several word choices.
- User selects the word that belongs to the category.
- Trial data records category, correct word, response, correctness, RT, and option count.

## Boundary

- Use as a vocabulary and semantic access exercise.
- Do not claim it is a standardized language assessment.
